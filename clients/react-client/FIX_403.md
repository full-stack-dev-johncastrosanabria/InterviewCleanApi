# Fix 403 Forbidden Error

## Problem
React client shows 403 Forbidden when trying to access `/api/*` endpoints.

## Root Cause
Vite dev server is blocking the requests instead of proxying them to the API.

## Solution Steps

### 1. Stop the Dev Server
Press `Ctrl+C` in the terminal running `npm run dev`

### 2. Clear Cache and Restart
```bash
# Clear Vite cache
rm -rf node_modules/.vite

# Restart dev server
npm run dev
```

### 3. Test the Proxy
Open in browser: `http://localhost:5173/test-proxy.html`

Click "Test /api/products" button. You should see:
- Status: 401 (Unauthorized) - This is CORRECT! It means the proxy is working.
- If you see 403, the proxy is NOT working.

### 4. Verify API is Running
In a separate terminal:
```bash
curl http://localhost:5000/api/products
```

Expected response: `401 Unauthorized` (this is correct - endpoint requires auth)

If you get connection refused, the API is not running:
```bash
cd ../../InterviewCleanApi.Api
dotnet run
```

### 5. Check Vite Config
Ensure `vite.config.ts` has:
```typescript
server: {
  cors: true,
  proxy: {
    '/api': {
      target: 'http://localhost:5000',
      changeOrigin: true,
      secure: false,
      ws: true,
    },
  },
}
```

### 6. Hard Refresh Browser
- Chrome/Edge: `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)
- Firefox: `Ctrl+F5` (Windows) or `Cmd+Shift+R` (Mac)

### 7. Check Console Logs
With the updated Vite config, you should see proxy logs in the terminal:
```
Sending Request to the Target: GET /api/products
Received Response from the Target: 401 /api/products
```

If you don't see these logs, the proxy is not intercepting requests.

## Alternative: Use Direct API URL (Temporary)

If proxy still doesn't work, temporarily use direct API URL:

**File:** `src/services/api.ts`
```typescript
const API_BASE_URL = 'http://localhost:5000';
```

**Note:** This will require CORS to be properly configured in the API (which it already is).

## Debugging Checklist

- [ ] API is running on `http://localhost:5000`
- [ ] Vite dev server restarted after config changes
- [ ] Browser cache cleared (hard refresh)
- [ ] Vite cache cleared (`rm -rf node_modules/.vite`)
- [ ] No other service running on port 5173
- [ ] Proxy logs appear in terminal when making requests

## Still Not Working?

### Check if Port 5000 is Accessible
```bash
curl -v http://localhost:5000/api/products
```

Should return 401 with CORS headers.

### Check Vite Version
```bash
npm list vite
```

If using Vite 8.x, there might be breaking changes. Try downgrading:
```bash
npm install vite@^5.0.0 --save-dev
```

### Check for Firewall/Antivirus
Some security software blocks localhost proxying. Temporarily disable and test.

### Use Network Tab
1. Open DevTools (F12)
2. Go to Network tab
3. Try to login
4. Click on the failed request
5. Check:
   - Request URL (should be `http://localhost:5173/api/auth/login`)
   - Status (403)
   - Response headers
   - Response body

If the request URL shows `localhost:5173` and returns 403, the proxy is not working.
If the request URL shows `localhost:5000` and returns 403, it's an API issue (but you said not to touch API).

## Expected Behavior

When working correctly:
1. Browser makes request to `http://localhost:5173/api/products`
2. Vite proxy intercepts and forwards to `http://localhost:5000/api/products`
3. API responds with 401 (no auth token)
4. Vite proxy forwards response back to browser
5. Browser receives 401 (expected for unauthenticated request)

For login:
1. Browser makes POST to `http://localhost:5173/api/auth/login`
2. Vite proxy forwards to `http://localhost:5000/api/auth/login`
3. API validates credentials and returns JWT token
4. Browser receives 200 with token
